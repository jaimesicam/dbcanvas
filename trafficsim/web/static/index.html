        What's this demonstrating?

        Every road/vehicle/signal/incident is a Valkey Hash (current state). Every event flows through a Valkey Stream with a consumer group (durable, resumable processing). Rankings are Sorted Sets. Vehicle and incident positions use Valkey's geospatial commands. Vehicles expire automatically (TTL) if their agent stops updating them. Live updates reach this page over Pub/Sub — but a full page refresh always recovers the same state straight from Valkey.
